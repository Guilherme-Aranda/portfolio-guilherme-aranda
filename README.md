Hello! Take a look at this README!

This is an academic project developed using only HTML, CSS, and JavaScript—without the use of any frameworks or libraries.
It is a portfolio-style website that includes information about me, my goals, and a contact form. The form uses the GET method, meaning the submitted data appears in the URL of the confirmation page. Consequently, the data is not stored in a database, though it may remain in the browser's history; as previously mentioned, the project was built using only basic front-end technologies. Feel free to test it out.
